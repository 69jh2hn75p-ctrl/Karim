## Выполнено в этом проходе

- Скилл `vizavi_motion` установлен в `.claude/skills/vizavi_motion/`: входной `SKILL.md`, маршрутизация по модулям и 10 модулей из переданных файлов. Ссылки между модулями совпадают с именами файлов.

## Ошибки, найденные и исправлены в ходе работы

1. **Рендер не стартовал**: Remotion пытался скачать Chrome с `remotion.media`, а хост недоступен. Причина: путь `browserExecutable` передавался в `renderMedia`, но не в `selectComposition`, который открывает браузер раньше. Исправлено: путь передаётся в оба вызова.
2. **Файл провалил проверку**: пиксельный формат `yuvj420p` вместо `yuv420p`. Причина: JPEG-промежуточные кадры дают полный диапазон цвета. Попытка через `ffmpegOverride` не сработала, потому что порядок аргументов не определял выбор формата. Исправлено переходом на PNG-кадры (`imageFormat: 'png'`). Валидатор при этом не ослаблялся.
3. **Субтитры перекрывали ноги персонажей** (видно в кадре 250). Исправлено: субтитры перенесены наверх кадра.
4. **Титры наезжали на персонажей и субтитры**. Исправлено: титры опущены в верхнюю треть.
5. **Жёсткий верхний край лабораторного прямоугольника** (видно в контактном листе). Исправлено: вертикальный градиент с плавным входом.

## Результаты тестов и проверок

- `npm run typecheck` (`tsc --noEmit`): без ошибок.
- `npm test`: 18 тестов, все проходят. Охватывают: кодек WAV (round-trip, заголовок, отказ на не-WAV, ресемплинг), синтез (длина, амплитуда), сцены без разрывов, пути персонажей, веса ходьбы, шаги только внутри фаз ходьбы, границы жестов и состояний, камеру (монтажные склейки, кадр в пределах zoom), позы (периодичность, жесты не трогают ноги), реплики (соответствие спецификации, попадание в сцену, без наложений, огибающая губ только у говорящего).
- `npm run build:audio`: три реплики. L01 — 94 кадра (3.13 с), L02 — 79 (2.63 с), L03 — 132 (4.40 с). Каждая укладывается в свою сцену.
- `npm run render:episode`: 720/720 кадров, файл записан, валидация пройдена:
  - H.264, `yuv420p`, 1920×1080, 30/1 fps, 720 декодированных кадров, 24.000 с
  - AAC, звук не тихий (средняя громкость −24 дБ, максимум −3.8 дБ)
  - длинных чёрных сегментов (≥1 с) нет
  - размер файла 5175 KiB
- Громкость по окнам (проверка, что звук по таймлайну, а не только есть дорожка): вступление 0–5 с −27 дБ, окна реплик и SFX −21…−23 дБ.

### Что проверено визуально

- Контактный лист (12 кадров через каждые 60): ходьба, Рен указывает на панель, Бо вскидывает руки, дверь открывается, лаборатория, титры.
- Полнокадровый кадр 250 (Рен указывает, Бо удивлён, субтитры сверху): силуэты читаются, шарф и рюкзак различимы.

### Что НЕ проверено

- **В движении**: видеоряд как поток не просматривался. Плавность ходьбы, камеры и переходов не оценивалась по последовательным кадрам.
- **На слух**: речь, музыка и SFX не прослушаны. Синхронизация звука с кадрами подтверждена по тайминг-данным, а не слухом. Громкость по окнам показывает, что звук есть в нужных местах, но не говорит о качестве и балансе.
- **Качество голоса**: espeak-ng звучит механически, это ожидаемо для запасного варианта.

## Решения, принятые без подтверждения (можно изменить)

- FPS 30, а не 60: из явного брифа (24/30 для YouTube). Умолчание скилла 60 fps уступает брифу.
- Формат промежуточных кадров PNG. Медленнее JPEG (78 с против 40 с), но корректный цвет.
- Локальный espeak-ng вместо внешнего TTS, потому что ключей нет.
- Процедурная музыка и SFX вместо библиотечных, чтобы не брать на себя лицензионные риски.
- Пиксельные и стилевые шесть частей из `styles-and-sources.md` сюда не применяются: проект в стиле cinematic stickman.

## Известные проблемы и долги

- Нет frontend и дашборда. Remotion Studio даёт только предпросмотр.
- Сценарий и персонажи захардкожены в коде, а не хранятся в базе.
- Нет SQLite и Prisma. Сохранения проекта нет.
- Нет очереди рендера, пресета 9:16 (Shorts) и русских субтитров (шрифт и кириллица не проверены).
- Ходьба — один цикл без смены весов и без инерции корпуса. Бег, прыжок и падение из брифа не реализованы.
- Флаги `WARN` в валидаторе не используются, кроме проверки чёрных кадров.
- Папка `.scratch-remotion-lic.v4Wv/` в корне репозитория — временная, созданная при проверке лицензии. Её удаление заблокировала проверка безопасности, поэтому удалить её нужно вручную. В коммиты она не включается.
