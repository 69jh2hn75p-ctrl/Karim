## 3. Архитектура MVP

```
stickman-ai-studio/
  src/engine/        чистая математика и таймлайн (без Remotion, покрыто тестами)
    timeline.ts      единый источник правды: сцены, реплики, шаги, SFX-метки
    choreography.ts  походка, жесты, состояния панели/двери/лаборатории
    camera.ts        камера по сценам (монтажные склейки и движения внутри сцены)
    dialogue.ts      схема JSON с таймингом реплик и огибающей губ
    math.ts          clamp, piecewise, easeInOut, tween
  src/characters/    ростер (внешность и голос), поза (pose.ts), SVG-риг (Stickman.tsx)
  src/scenes/        фон с параллаксом, субтитры, титры
  src/episode/       Episode001.tsx — композиция, собирает всё по кадру
  scripts/
    build-audio.ts   музыка, SFX, TTS (espeak-ng), огибающая губ -> JSON
    render-episode.ts  bundle + renderMedia -> exports/episode-001.mp4 + SRT + проверка
    lib/validate.ts  ffprobe/ffmpeg-проверка готового MP4 и отчёт о качестве
    lib/synth.ts, lib/wav.ts  процедурный звук, WAV-кодек
  tests/             18 тестов (node:test через tsx)
```

Каждый кадр вычисляется как чистая функция от номера кадра. Поэтому рендер детерминирован, а любой кадр можно перемотать назад и получить тот же результат.

## 4. Принятые решения

1. **Видео-движок — Remotion.** Это требование брифа. Remotion сам рендерит MP4 через встроенный компоновщик, поэтому отдельный запуск FFmpeg для сборки кадров не нужен. FFmpeg используется для проверки.
2. **Браузер — локальный `chrome-headless-shell`.** Remotion пытается скачать Chrome с `remotion.media`, а этот хост недоступен. Путь передаётся через `browserExecutable` в `selectComposition` и `renderMedia`. Это важно: `selectComposition` открывает браузер сам, и без этого параметра скачивание всё равно запускается.
3. **FPS 30, а не 60.** В основном мастер-брифе для YouTube указано 24 или 30 FPS. Модуль `review-and-export.md` задаёт умолчание 60 fps, но явный бриф имеет приоритет. Поэтому используется 30 fps.
4. **Промежуточные кадры — PNG, а не JPEG.** Пробный рендер с JPEG давал `yuvj420p` (полный диапазон цвета). Валидатор это поймал и отклонил файл. PNG даёт `yuv420p`, как и требует спецификация доставки.
5. **TTS — провайдер с двумя адаптерами.** По умолчанию espeak-ng: офлайн и детерминирован, голоса низкого качества. ElevenLabs включается через `TTS_PROVIDER=elevenlabs` и требует ключ и ID голоса на персонажа. Ключа нет, поэтому адаптер проверен только на подставном fetch.
6. **Музыка и SFX — процедурные.** Это оригинальный материал без лицензионных рисков.
7. **Frontend (React + Vite + Tailwind) и дашборд пока не сделаны.** Для предпросмотра используется Remotion Studio (`npm run studio`). Полный дашборд относится к Stage 4–10 и вынесен в журнал как незавершённое.
8. **Сценарий — провайдер с двумя адаптерами.** `manual` читает `projects/episode-001/screenplay.json`. `claude` вызывает Messages API, но без ключа не работает и не проверен вживую. Рендер пока читает `timeline.ts`, поэтому `check:story` сверяет оба источника.
9. **Ролики из скилла `vizavi_motion` применяются как принципы.** Шесть стилей учебного демо (карандаш, бумага, пиксель, SaaS/UI) к этому проекту не относятся: здесь стиль — modern cinematic stickman.
