# Stickman AI Studio

Студия для создания мультфильмов со стикменами. Идея превращается в эпизод: сцены, движение персонажей, диалог с мимикой губ, музыка, звуковые эффекты, субтитры и готовый MP4.

Сейчас готов **MVP первого этапа**: один оригинальный эпизод «The Lab Below» (24 с, 1920×1080, 30 fps, H.264 + AAC) рендерится из кода и проходит проверку готового файла. Дашборд, ИИ-сценарист и остальные модули брифа пока не реализованы. Подробный статус — в [docs/DEVELOPMENT_LOG.md](docs/DEVELOPMENT_LOG.md).

## Быстрый старт

```bash
cd stickman-ai-studio
npm install
npm run build:audio        # музыка, SFX, озвучка (espeak-ng), тайминг губ
npm run typecheck          # проверка типов
npm test                   # 36 тестов
npm run check:story        # сценарий валиден, раскадровка выведена, совпадает с таймлайном рендера
npm run build:audio:ep002  # эпизод 002 «Ash Road»: аудио и тайминг
npm run render:ep002       # эпизод 002: exports/episode-002.mp4 + SRT + проверка
npm run render:episode     # рендер exports/episode-001.mp4 + SRT + проверка
npm run studio             # предпросмотр в Remotion Studio
```

Для озвучки нужен `espeak-ng` (`apt-get install espeak-ng`). Для рендера нужен Chromium: по умолчанию используется `chrome-headless-shell`, а если его нет, Remotion пытается скачать сам. Путь можно задать через `REMOTION_BROWSER_EXECUTABLE` (см. `.env.example`).

Ключи API не нужны. MVP работает полностью офлайн.

## Что получается на выходе

| Файл | Что это |
|---|---|
| `exports/episode-001.mp4` | Готовый эпизод: H.264, yuv420p, 1920×1080, 30 fps, AAC |
| `exports/episode-001.srt` | Субтитры реплик |
| `exports/episode-001.quality.json` | Отчёт проверки готового файла (ffprobe/ffmpeg) |
| `exports/episode-001.contact.png` | Контактный лист кадров для визуального контроля |

Экспорт считается готовым только тогда, когда файл существует и проходит проверку. При провале `render:episode` завершается с ошибкой.

## Структура

```
src/engine/        таймлайн, хореография, камера, тайминг реплик (чистая логика, покрыта тестами)
src/characters/    ростер персонажей, модель позы, SVG-риг
src/scenes/        фон с параллаксом, субтитры, титры
src/episode/       композиция Episode001
scripts/           сборка аудио, рендер, проверка MP4
tests/             тесты node:test
public/            сгенерированные аудиофайлы (музыка, SFX, реплики)
docs/              план, журнал разработки, сжатый бриф
.claude/skills/vizavi_motion/  основной скилл motion-продакшна для этого репозитория
```

## Ограничения текущей версии

- Сценарий лежит в `projects/episode-001/screenplay.json`, но рендер пока читает `src/engine/timeline.ts`. `npm run check:story` следит, чтобы они совпадали. Адаптер Claude API написан, но не проверен с живым ключом, ключа нет.
- Адаптер ElevenLabs написан по публичному API и проверен на подставном fetch, но не с живым ключом.
- Озвучка espeak-ng звучит механически. Качество голоса — запасной вариант, а не финальный результат.
- Музыка и SFX процедурные: простой ambient-бед и несколько эффектов. Это не студийная музыка.
- Совпадение звука с кадрами проверено по тайминг-данным и по громкости в окнах реплик. Слуховой проверки не было, поэтому синхронизация отмечена как непроверенная на слух.
- Дашборд, таймлайн-редактор, очередь рендера в интерфейсе, референсы и TTS-провайдер ElevenLabs пока не сделаны.
- Remotion — платный для организаций больше трёх сотрудников (см. [docs/PLAN.md](docs/PLAN.md), раздел 2).
